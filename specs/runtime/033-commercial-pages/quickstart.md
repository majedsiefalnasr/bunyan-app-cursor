# Commercial Pages — Quickstart

## Frontend (Nuxt)

From repo root:

```bash
rtk cd frontend
rtk npm install
rtk npm run dev
```

## Useful Pages (Local)

- RFQs: `/rfqs`
- Orders: `/orders`
- Payments: `/payments`
- Invoices: `/invoices`

## Testing (Frontend)

```bash
rtk cd frontend
rtk npm run lint
rtk npm run typecheck
rtk npm run test
```
